## 1. 前端与业务验收

SSH 服务器管理回归：管理员入口/普通成员只读；挂载和粘贴配置解析；跳板、指纹确认和变更拒绝；错误密码与公钥安装；鲜绿色成功动画/保存；刷新持久化、删除和再次免密添加；375/768/1440 px 弹窗整体边界与内部无横向裁切。后端检查草稿归属/过期、并发幂等保存、取消胜过进行中的连接、重启恢复、密码不落库及删除版本冲突。执行证据见进度中的 SSH 增量。

此表为回归用例，是否通过以 `progress.md` 的实际证据为准。主分支提交 `92e2029` 的 [GitHub Actions 六个作业全部通过](https://github.com/xju-arlab/xju-lab/actions/runs/36694354217)，覆盖统一验证脚本、PostgreSQL 业务与权限回归、OIDC 成员自助登记/双用户浏览器闭环、前端响应式检查、Printer Agent 状态流程和隔离备份恢复。CI 虚拟 Agent 与虚拟 CUPS 不替代真实设备验收。

## 3. 证据边界

- 原型截图证明布局与交互，不证明真实登录、邮件、打印和采集可用。
- 后端契约测试不代替硬件试打与双账户联调。
- 只有已执行且结果可复查的测试记为通过；待编写测试和预期行为分开记录。
- 当前从 B00 开始持续实施，沿各包补齐有意义的契约、权限、并发和恢复测试；已通过的 UI 基础直接继承。
