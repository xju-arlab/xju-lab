# 请假邮件审批

## 用户流程

1. 成员选择一位实验室管理员，提交时间、原因及可选附件。
2. 指定管理员收到“实验室请假申请待处理”邮件，点击“查看并审批申请”。
3. 打开免登录详情页，点击一次“确认批准”；选择驳回时需填写原因，再点击“确认驳回”。
4. 申请人收到处理结果邮件与站内通知。

普通成员和教师不能担任审批人；仅启用的 LAB_ADMIN/SUPER_ADMIN 可选，不能审批自己的申请。其他管理员如需接手，须通过转交流程成为该单的指定审批人。

## 凭证与状态

- 链接有效期 72 小时。链接中的随机凭证仅对指定申请及收件管理员授权；无需再次统一登录，持有链接的人可处理该单，因此请勿转发。
- 邮件链接在 fragment 中传递凭证，网页通过 CSRF 保护的接口把 hash 放入服务端会话，随后清理地址。业务库只保留 hash，outbox 暂存加密值；不在浏览器持久缓存保存凭证或申请内容。
- GET/HEAD/预览/刷新不会批准、驳回或消费凭证；页面不自动提交。实际决策只能通过带 CSRF 的 POST 执行。此流程避免常见邮件链接预取造成误批，不承诺识别所有自动化浏览器。
- 每次预览、确认及待审批邮件发送都复核指定审批人、当前管理员权限、启用状态、申请待处理状态、凭证有效期。撤权、停用、转交、撤回或已审批后原链接不能继续操作。
- 申请锁在前、令牌消费在后；版本冲突和过期标签页拒绝提交。站内与邮件审批共用状态转换，同一次决定仅产生一次结果通知。
- 申请邮件附带原文件；邮件详情页按当前审批凭证限定到该申请提供文件下载及图片预览，所有请求重新校验权限与状态。只有识别到安全位图签名的文件可内联预览，伪装图片及其他类型保持下载。处理完成或链接失效后页面文件接口拒绝访问；已经收到或下载的文件副本不会被远程撤回。邮件正文只写申请人/时间摘要，详情页才展示原因。

## 发送配置与验证

- 使用既有 SMTP 环境变量及实验室设置 `mailEnabled`。生产邮箱沿用 huawei2 已配置的 SMTP，不在文档、日志或 Git 记录秘密。
- outbox 每 5 秒领取待发送通知；SMTP 异常退避，最多 8 次后进入死信。未启用邮件、无已验证收件地址或过时审批通知会明确记录抑制原因。生产启用前核对存量队列，不主动重放旧申请。
- SMTP 为至少一次投递：发送完成、落库前进程崩溃可能重复发信，但同一审批不会重复生效。SMTP 接受邮件并不等于实际邮箱已收到，生产送达仍需收件人确认。
- 后端集成回归使用真实 PostgreSQL/Redis；浏览器全栈回归通过隔离 Mailpit 接收待审批邮件，匿名预览/刷新/确认，再接收申请人结果。禁止向真实成员发送无关测试申请。
- 部署沿用 `cd /home/winbeau/projects/xju-lab && ./deploy.sh`，本次不新增环境变量或迁移。邮件开关由管理员设置控制；停用开关不改变已生效审批。
