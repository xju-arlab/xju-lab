> 2026-09-29。用户确认前端已基本成型，本计划接替“只做前端、每轮一步”的旧流程。以下保留 B00–B12 执行规格；当前实际状态以[进度记录](../progress.md)和[外部集成状态](../integration-status.md)为准。本地 B00–B12 验收已由 CI 实际运行；生产系统/设备、完整容量目标和上线验收仍待真实环境。

## 1. 目标、范围与完成口径

保留现有中文界面、品牌、工位确认布局和考核交互，将演示应用转为具备真实持久化与服务端授权的可运行系统。范围覆盖 R01–R12：身份/成员、工位、项目/待办、会议、请假、通知/文件/邮件、打印/Agent、监控、考核/OJ、公开展示、总览和 PWA。

一次提示词授权后，按 B00→B12 连续实施；每包结束记录证据并进入下一包，不再次索要普通实现选择，也不只交付方案、空 Controller、假成功或未调用的服务类。前端 F02–F09 剩余工作随对应后端模块补齐，不先重写一遍前端。A0–E 的映射见[路线图](03-roadmap.md)。

| 交付层级 | 必须具备的证据 | 不可替代的外部条件 |
|---|---|---|
| 本仓开发完成 | 全部业务代码、迁移、契约、真实数据库集成测试、现有前端 API 接入、Agent、运行配置、CI、端到端与恢复记录 | 本地依赖可安装/启动；测试替身需明确标识 |
| 外部集成验证完成 | 真实 Authentik 双账户登录、OJ 读取和角色同步、SMTP、exporter、打印机试打及故障演练 | 正式配置、受限凭据、目标项目配合及设备 |
| 可上线交付 | 上述证据齐全，生产配置检查、备份恢复、最小暴露面、部署/回退手册 | 用户指定部署目标并授权上线 |

缺外部配置时仍要完成本仓连接器、错误状态、受控契约测试和部署示例，将缺项写入 `docs/integration-status.md`（实施时创建）。有缺项时只能报告“本仓开发完成，以下联调待办”；不得声称项目已全面验收或上线。

不扩展首版范围：原生 App、多租户、真实考勤、GPU 调度、SSH 控制台、Office 转 PDF、自动判卷、复杂审批/收费、招新个人信息表单不在本轮。公开招新只展示联系方式和说明；旧 `POST /api/v1/public/applications` 占位在 B00 删除或明确标为未支持，不能为凑接口扩大范围。

## 3. 冻结默认值与运行模式

这些是可执行的工程默认值，不冒称用户已提供生产信息；有明确后续指示时更新决策和测试。

| 事项 | 默认实现 |
|---|---|
| 技术 | Java 21、Spring Boot、Spring Security OAuth2 Client、Spring Session Redis、MyBatis-Plus、Flyway、PostgreSQL；Maven Wrapper 固定版本与校验信息 |
| 依赖 | B00 根据官方兼容资料验证确切版本，锁定 BOM、前端锁文件和镜像版本；不为升级重做 UI，不使用浮动 `latest` |
| 模块 | 模块化单体，同库事务；同仓独立 Python Agent；不新增消息中间件 |
| 身份 | Authentik Authorization Code/OIDC + 后端会话；`iss + sub` 唯一；`icthub_account_id` 经验证后镜像映射 |
| 准入 | 有效统一身份 + 配置的产品准入组 + 本地有效成员；组名可配置，默认方案见 D12；缺 claim 拒绝，不默认放行 |
| 首位管理员 | 可信配置中的确切 issuer/subject 一次性引导，事务记录审计；不采用“首个登录者成为管理员”或默认演示姓名 |
| 请假 | 单级指定审批人、不能自批；允许跨天，`startAt < endAt`，默认不补假；PENDING/APPROVED 占用重叠区间；已批准由授权管理员撤销且留理由 |
| 考核 | 保留现有 25%/75% 和缺失值规则，缺考不自动补零；试卷量规可配置且随场次快照，不硬编码演示量规 |
| 时区 | 数据保存 UTC；业务默认 Asia/Shanghai，实验室配置可修改；培养期日期与考试发生时间分开 |
| 文件/配额 | PDF only 打印；可配置上传/页数/份数限制；配额首版统计、不收费；保留期默认建议见 Q09，生产显式确认 |
| 公开发布 | LAB_ADMIN/SUPER_ADMIN 审核发布；成员展示须单独许可；内部“实验室可见”不等于互联网公开 |
| 开发环境 | PostgreSQL/Redis、受控测试 IdP、本地 SMTP 收件箱、S3 兼容服务和 OJ/监控/打印适配器可按 profile 启动 |
| 生产环境 | OIDC、密钥、origin 等必需配置缺失时拒绝启动或显式禁用对应可选连接器；绝不静默使用开发账号/演示适配器 |

开发模式仍走数据库和正式业务服务。推荐独立测试 OIDC Provider；若另设 dev 身份入口，只能在显式 local/test profile、回环或隔离网络启用，生产配置检查和自动测试必须拒绝它。外部适配器只替换边界，不绕开授权、状态机或持久化。

## 4. 横向契约

### 4.1 权限与 HTTP

- 冻结 `contracts/openapi.yaml`，包括登录状态、CSRF 获取方式、资源操作、分页、字段、枚举、幂等、错误和对象权限。从它生成/校验前端类型，CI 检测漂移。
- `/api/v1/*` 使用后端会话，未登录 401、无权 403、不存在 404、状态/版本冲突 409、参数错误 400、依赖不可用 503。错误体统一 `{code,message,requestId,fieldErrors?}`；列表统一 `{items,total,page,pageSize}`，page 从 1 起、pageSize 默认 20/最大 100。
- 修改请求发送 CSRF；Session Cookie 在生产启用 Secure、HttpOnly、合适 SameSite。明确反向代理信任范围，禁止通配凭据 CORS；OIDC state/nonce/issuer 和回调来源必须校验。
- 更新有 `version`，事务比较并递增；关键创建/审批/打印/OJ 导入支持按用户与操作范围的 `Idempotency-Key`，相同键不同请求返回冲突。
- 所有列表、单条、下载、聚合、导出与后台任务遵循同一对象范围。审计记录 actor、目标、动作、前后状态摘要与 requestId，不存凭据和完整敏感文件。

| 能力 | 最低默认范围 |
|---|---|
| 匿名 | 已发布公开快照；不能读取内部成员、成绩、资源与文件 |
| MEMBER | 本人资料/申请/打印；所属项目与会议；成员可见工位基本资料；本人已发布成绩 |
| TEACHER | MEMBER 能力 + 被指定审批 + 所带团队成绩查看/录入；无关团队拒绝 |
| LAB_ADMIN | 成员准入、工位/设备/配置、请假转交、考核管理/导入/发布、公开内容；不能授予超级管理员 |
| SUPER_ADMIN | 实验室角色与关键配置；禁止移除最后一位有效超级管理员；跨系统同步单独显示确认状态 |
| Printer Agent | 仅绑定设备的拉取/确认/回报；不能读取其他业务 API 或任意文件 |

角色采用显式能力集合；项目内部的负责人/参与者、导师关系和成员状态额外约束对象权限。教职角色不自动成为全局管理员。姓名搜索和分页不能改变全局名次。

### 4.2 数据与状态

| 模块 | 最小实体与不可省略的约束 |
|---|---|
| 身份 | member、external_identity、role_assignment、mentor_relation；issuer/subject 唯一；账户冲突拒绝；停用保留历史引用 |
| 工位 | room、seat、layout_revision、seat_assignment；活动 seat/member 分配分别唯一；31 座位 ID 与确认 JSON 对齐，打印机/娱乐桌不接受分配 |
| 协作 | project、project_member、milestone、task、meeting、minutes_revision；会议行动项引用同一 task，不能双份状态 |
| 请假 | leave_application、leave_decision、approval_token；区间合法、同成员有效区间不可重叠；审批和撤回 CAS，令牌仅存 hash |
| 平台 | file_object、notification、outbox_event、audit_event、idempotency_record；外部副作用可重试和去重，文件归属明确 |
| 打印 | printer、agent_identity、print_job、print_event；作业 ID 稳定、租约和 fencing/version 防止过期执行者更新，统计以终态事实计 |
| 监控 | server_asset、alert_event；固定资产 ID 映射指标标签；原始时序留在 Prometheus |
| 考核 | training_term、term_member、exam、rubric_snapshot、grade_revision、assessment_import_job、contest/result_snapshot、ranking_snapshot |
| OJ 同步 | member_external_identity、角色期望/确认版本与 outbox；来源独立，乱序不能恢复旧授权 |
| 公开展示 | content_draft、published_snapshot、member_public_consent；撤回后匿名接口/缓存不再返回撤回内容 |

活动分配、请假区间、幂等记录与成绩唯一性由 PostgreSQL 约束/事务实现，不只靠“先查再插”。旧记录保留审计；迁移不可修改已发布版本。所有外部网络请求在事务外执行。

## 5. 执行包

### B00 工程、契约和验证基座（对应 A0.1；实现与 GitHub Actions 验收通过）

1. 检查工作区和可用 Java/Docker/Node/Python，保留已有修改。复跑前端基线，记录已存在的限制。
2. 创建 `backend/` Maven Wrapper 工程、配置分层、health/readiness、统一错误、审计/outbox 基础和首批 Flyway 迁移；健康接口不泄露环境秘密。
3. 创建 `contracts/openapi.yaml`、`deploy/compose.yaml`、`.env.example`、开发服务 profile、CI；示例不带真实密钥，数据目录被忽略。提供可复现启动和重置“仅测试数据”的说明。
4. 冻结 B01–B03 最小接口并建立 PostgreSQL 集成测试、接口验证以及前端 client 类型基座；后续每包同步扩展契约，不先造全部空路由。
5. 按现有页面拆 Shell/路由/数据适配层，保留演示模式；实现 requestId、loading/empty/error/401/403/409 处理，禁止调用失败转假成功。

**退出**：空数据库迁移、应用 health、真实 SQL 集成测试与前端构建通过；生产配置拒绝缺身份密钥/开发身份模式；README 的启动步骤经执行有效。

### B01 统一身份、成员与角色（A0.3；本地实现，生产 IdP 待联调）

实现 OIDC 登录/回调/注销、`GET /api/v1/session`、CSRF、会话失效，成员准入、本人资料、导师关系、角色管理、首位管理员引导、设置读写。SUPER_ADMIN 变更事务写 OJ 同步期望与 outbox，外部发送在 B10 接通。

前端增加登录引导和路由守卫，将设置/个人资料接 API；不能复制飞跃的 localStorage token 或演示角色切换。资料字段可见范围与工位气泡保持一致，仅授权者能看联系方式等私密字段。

**退出**：两个账户的数据隔离、角色/对象越权、身份冲突、停用/撤权后的既有会话、CSRF、最后管理员保护、无身份配置均有测试；刷新与后端重启保留资料。真实 Authentik 配置缺失列外部待办。

### B02 工位、房间与真实分配（A1.1；本地实现，真实名册待接入）

以确认 JSON 初始化布局元数据，定义布局 schema 校验、版本保存/历史、管理员标定、成员分配/解除/维护规则。服务端检查成员有效、工位可用、每人一个活动工位；变更写历史和审计。列表投影只展示请假状态，不公开原因。

把已有工位页面接到统一 member ID 和 API，保留气泡、网格吸附、保存/取消、导入导出和配色；版本冲突提醒重新加载，不能静默覆盖另一人的布局。

**退出**：双用户并发抢位仅一人成功、同人重复分配被拒、无权标定被拒、刷新/重启后布局和分配保持；现有工位测试、SVG/PNG 实际内容与四边留白通过。

### B03 项目、任务、会议与总览（A1.2；实现与 PostgreSQL 集成测试通过）

实现项目/成员/里程碑、统一 task、会议议程/参与者/纪要版本/行动项 CRUD，成员范围授权、归档、版本冲突。会议行动项与项目/我的待办引用同一记录。统计从数据库推导：必需里程碑零分母为“未设置”，项目和任务进度分别统计。

抽出并接入项目、会议、总览页面；总览只聚合当前用户有权访问的数据，不将演示硬编码统计留在正式模式。按分页/筛选查询，防止逐行 N+1。

**退出**：从会议创建行动项→我的待办→完成→项目和总览一致；无关成员直接请求/搜索不能看到项目；跨路由、刷新及重启保持；并发修改返回 409。

### B04 请假与站内审批（A1.3；本地实现，生产 SMTP 待验证）

状态为 `PENDING → APPROVED/REJECTED/WITHDRAWN`；已批准仅授权管理员可转 `REVOKED`。指定审批人不能是本人；普通申请人只能撤回待批申请，转交必须审计。以数据库并发约束校验有效区间重叠，跨日按业务时区显示。

接入申请、审批、驳回、撤回、转交和管理员撤销，写站内通知/outbox，工位与总览派生当前请假状态；SMTP 不可用不影响站内闭环。

**退出**：非法/重叠时间、自批、跨用户请求被拒；审批与撤回竞态只有一个成功；半开区间边界、跨天、时区、原因可见性、审计和状态投影均有证据。

### B05 私有文件、通知和邮件（B.1/B.2；本地实现，生产 S3/SMTP 待验证）

实现文件元数据、私有上传/授权下载/Range、MIME 与魔数校验、大小限制、PDF 解析/页数/加密文件拒绝、对象清理和孤儿回收。日志不暴露文件内容；客户端声明的页数不可信。解析使用受控资源和超时。

实现站内通知列表/已读、outbox worker 领取租约/退避/失败状态、SMTP 模板及收件人规则；用本地收件箱测试，不向真实联系人试发。请假邮件令牌存 hash、有过期时间且绑定申请与审批人；GET 只展示，SSO 后 POST 原子消费，同一次审批不重复通知。

**退出**：私有文件无法越权下载，非法 PDF/Range/超限被拒；业务提交后 worker 崩溃重启可恢复；邮件链接扫描、过期/重放、错误审批人均不触发审批；失败重试和去重可复查。

### B06 考核领域、服务端计分与管理（E.1 的本地部分；本地实现，OJ 双系统待联调）

实现培养期/资格/老成员标记、ACM 快照、理论考试、可配置量规、录分/修订/审核/发布、双排行和 CSV 导出。后台输出源版本/算法版本/计算时间/有效场数，前端仅渲染权威结果。

完全复现[09 专项](../design/09-assessment-and-showcase.md)：过滤影响每场 N，并列平均占位，单人 50，0 分有效，缺考/无记录不补零，无历史回退当次，无当次不排名，同期历史不包含当前/未来，单场 kind 互斥。修订影响之后场次，但不能静默改写已发布快照。

抽取可共享输入/期望值的 JSON 测试向量，让 Java 与现有 TypeScript 同时读取；覆盖同一天多场事件排序和浮点/显示精度。补齐原型未有的培养期/考试/量规/发布管理页面，仍沿用现有 UI。

**退出**：同一向量前后端结果一致，数据库约束/权限/修订/发布/过滤/搜索分页通过；CSV 落盘内容、Unicode、公式注入处理核验；跨设备读取一致。OJ 网络导入在 B10 完成。

### B07 打印服务与持久队列（C.1 服务端；本地实现）

实现打印机资产/能力、文件绑定、页码规范化与去重、份数/单双面/颜色校验、逻辑面数与纸张估算、提交/取消/状态事件、设备凭据及心跳。后端再次校验 PDF 页数和设备能力。

冻结 `contracts/printer-protocol-v1.schema.json` 与状态转移：`QUEUED → LEASED → SUBMITTING → SUBMITTED → COMPLETED/FAILED`，取消使用 `CANCEL_REQUESTED/CANCELED`；是否已被 CUPS 接收无法确定则 `UNKNOWN`，禁止自动重打。过期租约只能安全重领尚未提交任务；过期 Agent 的回报不能覆盖新版本。

前端接真实上传和任务查询/进度，取消有真实确认状态，不能点按钮即假定物理打印停止。初版可轮询，Agent 主动 WSS/HTTPS 连接，不暴露公网 CUPS。

**退出**：重复提交幂等、两 Agent 竞争、过期回报、断网/取消竞态、非法页码和能力不支持均测试；服务器重启队列不丢失。

### B08 树莓派 Printer Agent（C.0/C.1/C.2；Agent 与虚拟 CUPS 本地通过，实机待试打）

创建独立 `printer-agent/` Python 工程、锁定依赖、配置示例和 systemd 模板。实现设备身份、主动连接/退避、授权下载、内容校验、SQLite journal、CUPS/IPP 适配器、能力与耗材探测、状态上报/取消及日志脱敏。

先记录 SUBMITTING 与稳定作业标识，再调用 CUPS；恢复时根据 journal 与 CUPS 作业标识核对。CUPS 已接收但应答丢失时不能再次提交；确认不了进入 UNKNOWN 并要求人工核对。耗材 unsupported/unknown 和空耗材分开显示，阈值抑制重复告警并记录恢复。

**退出**：受控 CUPS 测试端下真实进程重启、提交应答丢失、重复消息、下载损坏、取消、断网、耗材未知均有证据；实机驱动/单双面/彩色/纸张试打单列外部验收，不以测试端成功替代。

### B09 服务器监控与告警（D；本地实现，真实 exporter 待验证）

实现资产登记、Prometheus 受限后端适配、固定指标模板、时间范围/步长限制、CPU/RAM/磁盘/负载/GPU 摘要和短期曲线。指标响应包含单位、采样时间、过期阈值/状态；缺数据不转成零，旧值明确过期，CPU 占位不加入未知容量汇总。

区分平台查询不可用、exporter 不可达、GPU 不支持、从未配置；连接器超时降级不影响核心 API。告警/恢复以状态变化去重，经 B05 通知；浏览器不能查询任意 PromQL、任意 target 或持有监控凭据。

**退出**：受控指标源验证单位、聚合、过期、平台故障与设备故障、恢复去重；至少一台真实 CPU/GPU exporter 的验证在可达时补齐，否则列外部缺项。

### B10 OJ 单链接导入与管理员同步（A0.4/E.1；LabOS 侧实现，OJ 目标端待补接口）

按[11 专项](../design/11-oj-import-and-admin-sync.md)实施完整后台任务：origin 白名单/固定路径构造、仅最终 ACM 榜、全量分页/版本一致、稳定身份映射、WAITING_MAPPING、原始快照、哈希去重、重判修订、原子发布，失败保留旧榜。

实现 SUPER_ADMIN 的期望角色→事务 outbox→受限角色来源接口→确认版本/状态，撤销/停用、独立来源保留、旧会话失效、递增版本、重复/乱序、有限租期和定期对账；目标默认为 OJ Admin，不是 Super Admin。

**两仓依赖处理**：OJ 当前尚无计划中的受限成绩/角色接口，现有 OIDC 覆盖逻辑需改造。先只读盘点相邻 `xju-oj` 的当前版本和指南；无跨仓修改授权时，在本仓 `integrations/xju-oj/` 交付针对记录 commit 的补丁、契约、应用/回退说明和测试报告，可在临时隔离副本验证，不改原参考工作区。源码不可用时交付精确接口契约和缺项，不能伪造“补丁已验证”。已有明确跨仓授权时按目标仓约定实施并保留其原有修改。

**退出**：LabOS 端完整接口/页面和受控 OJ 契约测试通过；一链接导入全场、映射冲突、封榜/OI/无权/超时/重判/乱序均覆盖。OJ 补丁和真实双系统联调各自登记状态，缺任一项不能标记跨系统能力完成。

### B11 公开展示、PWA 与前端收尾（E.2/E.3；本地实现及 CI 浏览器矩阵通过）

实现介绍、方向、成员许可、成果/论文/项目/新闻/招新说明的草稿、预览、发布版本、下架和公开 API；富文本净化，公开响应显式白名单。公开首页放在 `/`，内部 `/app/*` 守卫，不再把根路由直接跳到演示总览。

PWA 缓存仅 hash 静态资源和离线页；API/OIDC/审批/私有文件不缓存、不离线排队写入。实现更新提示和离线不可操作反馈。前端正式路径不再依赖 demo 成员、硬编码统计和本地业务缓存，保留显式可选 demo 模式。

**退出**：草稿、撤回内容、无公开许可成员与内部字段无法匿名获取；SW cache 只含离线页与 hash 静态资源；13 个内部路由在 375/768/1440 px 无页面溢出；移动导航键盘 Enter/Esc/焦点、加载/503 错误/重试、空/无权状态和路由浏览通过；CSV/SVG/PNG 下载内容核验。屏幕阅读器与真实设备辅助功能另行人工检查。

### B12 全栈验证、运维与交付（隔离浏览器/恢复 smoke 通过；生产验收仍待完成）

1. 完成可复现的 Compose/Nginx 配置：API/OIDC/WS 优先路由，未知 API 返回 JSON 404；TLS/反向代理说明、非公开管理端口、健康检查、持久卷和必要资源限制。
2. 创建并实际验证统一检查/启动脚本，覆盖前端构建与回归、后端 verify、契约、Agent、数据库迁移、生产配置检查和关键端到端。CI 直接运行 `scripts/verify.sh`，并在 Compose + 本地 Keycloak 中通过浏览器验收。CI 不依赖开发者本机的相邻仓库或秘密。
3. 浏览器端到端覆盖：OIDC 管理员/双成员登录、项目/共享任务和隔离、会议纪要与行动项、请假审批和已读通知、私有 PDF→打印队列→Agent 鉴权下载和状态版本、理论成绩历史及发布、匿名公开发布与撤回。ACM/OJ 真实端联调待 OJ 端接口。13 个内部路由逐一在 375/768/1440 px 检查页面级溢出；移动导航 Enter/Esc/焦点、加载/503 错误/重试、空/无权页面、静态 SW cache 和 CSV/SVG/PNG 文件内容都经 CI 浏览器验证。屏幕阅读器和真实设备辅助功能留给人工检查。
4. 对测试数据库和文件执行备份/恢复演练，验证实体/关联/对象一致，记录用时和限制；CI 已在 PostgreSQL 17.6/RustFS 上用专用探针表及私有对象运行备份与恢复，验证恢复行引用的对象字节、目标桶精确同步和 43 秒 job 用时。该探针不替代完整应用库、生产数据一致性、RTO/RPO 或生产灾难恢复验收。提供生产备份、迁移、回退与灾难恢复说明，不把备份“脚本存在”当恢复成功。

6. 清理正式模式占位/假成功，扫描提交内容，保留许可，完善 README、部署手册、API/Agent 文档、`integration-status.md`、进度和交接。按用户授权 add/commit/push，并核对远端 commit；不擅自触发生产部署。

**退出**：R01–R12 对应验收均有“通过/失败/外部待验证”及证据，检查失败已修复；未完成项不隐藏。最后报告提交、启动方式、验证结果和外部缺项。只有生产外部验证齐全才能写“全部验收完成”。

## 7. 状态与证据登记模板

每包在 `docs/progress.md` 更新：编号/状态、实现文件、实际执行命令与结果、数据/浏览器证据、外部依赖、下一步。`docs/integration-status.md` 至少含服务、代码状态、本地验证、真实验证、缺项、最后检查日期，不保存密钥。

状态限定为：未开始、进行中、本地通过/外部待验证、全部通过。不可把“测试被跳过”“替身成功”“文档已写”记为全部通过。从第一个未完成包续做；外部待验证但本地已通过的包不阻塞无关后续包。
