## 2. 通用设计约束

- API 用 camelCase，SQL 用 snake_case，业务 ID 默认 UUID，时间戳保存 `timestamptz` 并以 RFC 3339 带时区格式交换。
- 日历日期（里程碑日、学期起止日）用 `date`/`YYYY-MM-DD`；时间区间统一左闭右开 `[start,end)`。
- 所有写操作有输入校验、服务端权限、对象状态校验、必要的乐观锁/唯一约束及审计；审批/打印创建等额外支持幂等键。
- 数据库与外部服务不组成跨系统长事务；可靠异步发送用 outbox，副作用接收端去重。
- 状态未知、外部暂不可用、设备不支持能力属于明确产品状态，不能统一显示“成功/0%/正常”。
- 前端隐藏按钮不是权限控制；数据库表行的 UUID 也不是授权证明。
