# 工位布局与交互

更新：2026-09-30。正式 API 模式与显式 demo 模式共用确认布局及气泡定位，入口 `/app/seats`。

## 正式 API 模式

- 工位、布局与成员从服务端读取，PostgreSQL 保存分配和布局版本；浏览器缓存不是业务权威源。31 个可坐位的默认坐标保持不变。
- 点击桌面就地显示带三角指向的 8px 小圆角卡片，展示工位编号、成员姓名、班级、方向；`onLeaveNow` 为真时展示“当前请假”，不展示请假原因。不再把普通成员信息放到地图下方。
- 气泡根据桌面和可用视口空间选择左右或上下位置，随滚动/窗口尺寸更新；支持外部点击关闭、Escape 关闭并将焦点归还桌面。窄屏限制卡片边界，内容过长时在卡片内部滚动。
- 管理员可以在空位气泡内用统一 ComboBox 选择未分配成员并保存，也可以解除分配；普通成员只读。设施不参与分配。接口失败在气泡内显示，保存期间阻止重复操作。
- 服务端返回的班级、年级与方向直接显示，缺项标记未填写；即使姓名与演示名册相同，也不从 demo 补全资料。年级值 24/25/26 转为对应的 2024/2025/2026 配色，其他年级使用中性色。
- 标定模式仍保留单独的布局调整控件与版本冲突反馈；SVG/PNG 导出沿用已有流程。布局 API、字段与权限以 `contracts/openapi.yaml` 为准。

下文的浏览器本地存储、示例名册和高级标定操作属于显式 demo 模式的原型记录；不代表正式 API 模式的数据存储或权限。

## 标定操作

- 拖动桌位或墙窗控制点，位移始终按 10 单位吸附，无单独吸附开关。小数桌宽保留，避免破坏 130% / 95% 比例。
- Shift 点击多选，整排按钮选择 A–I 或 B+C、D+E；整组共享同一位移，不破坏相对位置。方向键 10 单位，Shift + 方向键 50 单位，R 旋转。
- 右侧属性可调坐标、桌面尺寸、朝向、墙角、门窗和工具区；“整理对齐”统一行列与桌面外沿，重复执行不漂移。
- 支持撤销/重做、恢复项目标定、导入/导出 v4 布局 JSON。导入限制 64 KB，校验完整桌位 ID、尺寸、坐标、门窗及版本，不执行文件内容。
- 保存或关闭标定开关写入当前浏览器；取消恢复进入标定前的布局。离开页面前应先保存，未保存草稿不跨页面保留。

## 存储和导出

布局覆盖值键 `xju-lab.seat-layout.v1`，成员分配键 `xju-lab.seat-assignments.v1`。首次访问使用固化默认值，坏数据回退。不同浏览器、端口及主机名属于不同存储来源。布局可导入导出迁移，当前没有服务端同步。

页面 SVG/PNG 导出使用当前布局，去掉选择框、筛选淡化及调整手柄；标定模式导出不含成员姓名。导出复制图形后测量实际绘制范围（包含描边、旋转的桌椅和墙窗），四边增加相同的 40 图形单位留白。SVG 的尺寸与 viewBox 同比例，背景覆盖整个导出范围；PNG 按 2 倍分辨率生成、不透明背景。没有沿用页面固定画布宽高，调整后位于墙外的家具也完整保留。

静态无分配的页面版 SVG 可运行 `pnpm export:floor-plan` 生成到 `frontend/public/lab-floor-plan.svg`。它保留页面画布范围；需要四边等距裁切时使用页面导出按钮。

`contracts.ts` 仅登记成员列表、布局读写和工位分配建议接口。接入后端时应校验布局版本与管理员权限，分配用稳定成员 ID 和唯一约束，返回真实班级、年级、学号、联系方式和方向数组；现有前端没有调用这些接口。

## 验证

`pnpm test:seats` 覆盖最终标定来源、归一化幂等、同行等距、成对列对齐、工具区与娱乐桌桌面边界、组合吸附、墙窗约束、布局校验、重复分配阻止、年级配色和 SVG 座椅数量。开发服务器 `/tests/seat-export-preview.html` 检查实际 SVG/PNG 的尺寸、四边像素留白、不透明背景、过滤/选中态清理以及家具超出墙体的情况；它仅是开发检查页，不属于生产入口。浏览器验证记录见 [进度](../progress.md)。
