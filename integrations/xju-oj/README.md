# XJU OJ 集成交付状态

LabOS 侧固定用途连接器、链接导入队列、来源角色 outbox、版本确认和受控响应测试已在本仓实现。目标 OJ 当前缺少下述服务接口，故真实导入和管理员联动尚未完成；不把连接器单测称为双系统集成。

本交付只记录接口约定，不修改相邻 `../xju-oj/` 项目，也没有应用或验证 OJ 补丁。设计来源为 2026-09-29 盘点的 OJ 工作区提交 `f6b1cda3efcffce5a10a310762cfd1c6c268bb8f`。该版本现有 OIDC 登录会覆盖部分本地管理员角色，不能直接向其写 `admin_type` 来实现 LabOS 来源授权。具体 API 和安全约束见 [contract.md](contract.md)。

恢复联调的顺序：在 OJ 增加受限接口和来源独立授权表；以 OJ 自身迁移/权限测试验证独立 OJ 管理权限不被 LabOS 撤销；在双方测试环境验证完整分页、版本一致、重复事件、乱序撤销和已登录会话权限刷新；最后更新本文件与 `docs/integration-status.md` 的实际结果。
